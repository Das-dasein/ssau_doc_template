# Шаблон оформления документации (MS Word)  
**Кафедра ИСТ**

Этот репозиторий содержит шаблон оформления документации. Шаблон разработан с использованием стилей Microsoft Word. 
Сам шаблон находится в файле [template](./template.docx).
Корректность тестировалась на версии "Microsoft® Word для Mac" Версия 16.102.2.

---

## 📌 Доступные стили

Шаблон основан на использовании следующих стилей:

| Стиль                  | Назначение |
|------------------------|------------|
| `Заголовок 1`          | Структурные элементы / заголовки приложений |
| `Заголовок 2`          | Заголовки разделов |
| `Заголовок 3`          | Заголовки подразделов |
| `Заголовок 4`          | Заголовки пунктов |
| `Заголовок 7`          | Разделы приложения |
| `Список ненумерованный`| Маркированные списки |
| `Список букв.`         | Списки с буквенной нумерацией |
| `Список нумеров.`      | Нумерованные списки |
| `Название объекта`     | Заголовки таблиц |
| `Формула`              | Строки с формулами (с автоматической нумерацией через счетчики) |
| `Название рисунка`     | Подписи к рисункам |

> ⚠️ **Важно**: Использование `Заголовок 7` для приложений нарушает стандартную иерархию заголовков в Word (например, он не эквивалентен по уровню `Заголовку 2`). Это вынужденное решение, вызванное ограничениями Word: невозможно назначить один уровень заголовка разным визуальным стилям. Если у вас есть идеи, как это улучшить — присылайте PR!

## 📝 Рекомендации по использованию

### Рисунки
- Для добавления подписи используйте: **ПКМ → Вставить название**.
- Текущая реализация стиля `Название рисунка` поддерживает **только глобальную нумерацию** (не в рамках раздела).

### Таблицы
- При разрыве таблицы на несколько страниц:
  1. Выполните **разрыв таблицы**.
  2. На следующей странице вставьте **новую таблицу**.
  3. Добавьте строку с надписью **«Продолжение таблицы»** вручную.  
  *(Это ограничение Word; автоматическое решение пока не найдено.)*

### Список использованных источников
- Номера источников **не содержат точки** после цифры (например: `1`, а не `1.`).
